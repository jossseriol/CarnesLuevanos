# Carnes Luévanos

Sistema administrativo para ventas, inventario, compras, clientes, proveedores, pedidos, nómina y reportes.

El proyecto incluye:

- Aplicación de escritorio desarrollada en Python.
- API local para sincronización de datos.
- PWA optimizada para iPhone.
- Configuración opcional para despliegue con Docker y MySQL.

## Instalación

Consulta los archivos de dependencias según el entorno:

- `requirements-desktop.txt`
- `requirements-api.txt`
- `requirements-cloud.txt`
- `requirements-cloud-mysql.txt`

La PWA se encuentra en `pwa-iphone/` y requiere Node.js 22.13 o posterior.

## Datos privados

Las bases de datos locales, facturas, perfiles, códigos QR, credenciales y archivos de entorno no forman parte del repositorio.
